# 🧩 DS&A Practice
A collection of common Data Structures and Algorithms implemented in **Swift** and **Kotlin**. 

This repository serves as my personal playground for practicing algorithmic thinking and comparing how different paradigms approach the same problems.

## 🗺️ Learning Roadmap
I am following this structured path to master algorithmic thinking:

| Order | Topic | Focus |
| :--- | :--- | :--- |
| 1 | **Arrays & Hashing** | Frequency counting, HashMaps, Sets |
| 2 | **Two Pointers** | Searching pairs and sequences |
| 3 | **Sliding Window** | Optimization in contiguous sequences |
| 4 | **Stack** | LIFO operations and parsing |
| 5 | **Binary Search** | Logarithmic time searching |
| 6 | **Linked List** | Pointer manipulation and traversal |
| 7 | **Trees (BFS/DFS)** | Hierarchical data and recursion |
| 8 | **Graphs** | Pathfinding and connectivity |
| 9 | **Heaps / Priority Queue** | Efficient extraction of extremes |
| 10 | **1-D Dynamic Programming** | Overlapping subproblems and memoization |

## 📁 Repository Structure
Every topic folder contains two sub-folders or direct files, one for each language:
- `TopicName/Solution.swift`
- `TopicName/Solution.kt`

## 💡 Code Standards
Every implementation includes:
- **Time Complexity:** $O(n)$
- **Space Complexity:** $O(n)$
- **Idiomatic Logic:** Using Swift's Protocol-Oriented patterns vs. Kotlin's functional/data-class patterns.
